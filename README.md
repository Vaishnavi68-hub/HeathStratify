# Health Stratify 🩺

Health Stratify is a machine learning project that predicts health-risk classifications using different health and lifestyle factors.

I explored the complete ML workflow here — from data cleaning and EDA to model training, evaluation, hyperparameter tuning, cross-validation, and ensemble learning. The final model is integrated into a simple Streamlit app where users can enter their details and get a prediction.

**Tech:** Python, Pandas, NumPy, Scikit-learn, Streamlit
